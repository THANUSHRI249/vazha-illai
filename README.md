# 🌿 Vazha Ilai - Banana Leaf Restaurant (வாழை இலை உணவகம்)
> **VibeAthon6.0 (Vibe Coding Hackathon) 2K26 — Smart Restaurant Management System**
> **Achieved Level: 💎 Platinum Level (User Stories 1–5) + 🌟 Bonus Innovation**

A modern, cultural South Indian restaurant web application built with a zero-API, lightweight tech stack. Features authentic Tamil aesthetics, cute cultural affirmations, 20 signature delicacies, live inventory synchronization, table reservations, live waiting queue, content creator collaboration, express home delivery, and an AI-inspired **Smart Hunger & Food Waste Portion Predictor**!

## 🏆 Completed User Stories & Ranking System

### 🟢 Bronze Level — User Story 1 (User Experience)
- [x] Modern, intuitive, South Indian cultural UI inspired by banana leaf emeralds (`#1b4332`), turmeric gold (`#e9c46a`), and clay terracotta (`#bc4749`).
- [x] Cute minimal Tamil hospitality affirmations (*"அன்போடு உபசரிப்பு"*, *"உணவே மருந்து"*, *"விருந்தோம்பல் நம் பண்பாடு"*).

### ⚪ Silver Level — User Story 2 & 3 (Authentication & Digital Operations)
- [x] **User Story 2 (Authentication)**: Email & Password auth with simulated 4-Digit OTP verification + 1-Click Google OAuth simulation + Role-based access control.
- [x] **User Story 3 (Digital Workflows)**:
  - **Digital Menu**: 20 authentic Tamil items with live stock status badges (*In Stock / Out of Stock*), price in ₹, Tamil & English names, category filters, and search.
  - **Smart Table Reservation**: Choose date, time slot, guest count, seating style (*Traditional Floor Leaf / AC Table*), and instant confirmation token.
  - **Live Virtual Queue Management**: Real-time queue count & wait time estimate, virtual token issuance (`Q-101`), call-next queue manager.
  - **Content Creator Collaboration**: Food blogger application form (*YouTube / Instagram foodies*).
  - **Express Home Delivery**: Eco-friendly banana leaf thermal packaging order flow with live order step tracker.
  - **Interactive Cart & Billing**: Slide-out cart drawer, discount promo code (`TAMIL10`), auto tax calculation, and printable Banana Leaf Bill Receipt (`#VI-9021`).

### 🟡 Gold Level — User Story 4 (Restaurant Management Dashboard)
- [x] **Staff Management Dashboard**: Quick 1-click toggle between Customer & Staff View (`staff@vazhailai.com` / `admin123`).
- [x] **Live Inventory Control**: Toggle items in/out of stock or modify stock count in real-time, instantly reflecting on the customer digital menu!
- [x] **Order Status Manager**: Update active customer orders (*Preparing -> Ready -> Completed*).
- [x] **Queue & Reservation Controls**: Approve table bookings and seat waiting queue groups.
- [x] **Operational Insights**: Real-time revenue, active orders, and stock alerts.

### 💎 Platinum Level — User Story 5 (Intelligent Operations)
- [x] **Smart Portion & Hunger Advisor**: AI-inspired portion recommendation engine matching hunger levels (*Light, Mid, High*) and demographics (*Adults, Kids, Seniors*).
- [x] **Personalized Recommendations**: Suggests optimal meal combos (e.g. *Sambar Sadam + Moru* or *Ghee Roast Dosa + Degree Coffee*).
- [x] **Smart Notifications**: Toast alerts for live availability changes & queue status.

### 🌟 Bonus Level — Additional Innovative Features
- [x] **Zero Food Waste Calculator**: Predicts & prevents ~180g of food/rice waste per order.
- [x] **Content Creator Collaboration Module**: Digital application portal for Instagram/YouTube food bloggers.
- [x] **Express Eco Banana Leaf Delivery**: Express delivery tracking with thermal leaf packaging.

## 🚀 How to Run Locally

Because of the minimal, zero-API architecture, no complex build steps or node modules are required!

Simply open `index.html` in any web browser!

Or launch a local server using PowerShell:
```bash
npx serve .
```
or
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.

## 🐙 How to Push to GitHub in 3 Easy Steps

Run these commands inside your project folder:

```bash
# 1. Open project directory
cd "C:\Users\THANUSHRI K\.gemini\antigravity\scratch\vazha-ilai-restaurant"

# 2. Link your GitHub Repository (replace with your username)
git remote add origin https://github.com/YOUR_USERNAME/vazha-ilai-restaurant.git

# 3. Push to GitHub
git branch -M main
git push -u origin main
```

To enable 1-Click Live Hosting on GitHub Pages:
1. Go to your GitHub repository -> **Settings** -> **Pages**.
2. Under **Source**, select **`main` branch** and click **Save**.
3. Your app will be live in 60 seconds!
